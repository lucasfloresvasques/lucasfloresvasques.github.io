# ACM — exemplo didático sintético

160 observações **inteiramente simuladas**. Não contêm respostas reais e não
representam padrões empiricamente observados na população brasileira.

Arquivos: `dados_sinteticos.csv` e `acm_exemplo.R`.

Requer R e o pacote `FactoMineR`. Extraia em uma pasta, inicie R com essa pasta
como diretório de trabalho e execute `source("acm_exemplo.R")`.
O script produz os autovalores, um mapa de categorias e uma classificação
hierárquica. Não reproduz resultados de nenhum manuscrito em avaliação.
